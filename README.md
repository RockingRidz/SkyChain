# SkyChain
SkyChain is a compact PCB keychain that tracks live flights overhead. Powered by an ESP32 and a 0.96" OLED screen, it uses Wi-Fi to fetch flight numbers, altitude, and routes via the OpenSky API. The board features custom I2C routing, USB-C charging via TP4056, a 3.3V regulator, tactile buttons, and a keyring hole.
